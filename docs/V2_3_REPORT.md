# V2.3 — 카메라 앞 확대 · 프레임 기준 판정

## 변경한 점수·판정 규칙 (dist/index.html)
- `depthScale(y)`: y≥0 은 기존과 동일(최대 1, 하한 .68). **y<0(발이 프레임 아래)** 은 `1 - y*0.025` 로 1 초과 확대 (y=-30 → 1.75배).
- `MIN_Y=-30`, `minYFor(pose,hc0)`: 얼굴 앵커가 프레임 바닥에서 12% 이상 위에 남는 가장 낮은 y. 이보다 앞으로는 못 내려가 **다시 잡을 수 없는 상태 방지**.
- `big`: 규칙 문장은 그대로(내 배율 ≥ 나머지 평균×1.12). 이제 카메라 앞(y<0)으로 나오면 달성.
- `faceVisible`: 변경 없음 — 원래도 프레임(5~95%, 3~92%) 기준 + 앞사람 가림 판정. 전신을 요구하지 않는다.
- `close`(엄마·아빠 붙기): 몸 전체 bbox 중심 → **프레임 안에 찍히는 부분의 중심**(`ctr`).
- `staged`(연출포즈 인원): 얼굴이 **프레임 안**일 때만 인정.
- 드래그: 잡은 지점과 발의 거리(`oy`)를 유지해 손가락이 화면 아래로 못 가도 발이 프레임 밖까지 내려감. 사고 이동(`planMoves`)의 y 하한도 `minYFor`.
- 포즈 변경(`fitInStage`): 새 포즈의 얼굴이 프레임 밖이 되면 y 만 올려 보정.

# V2.5 — 바닥 한계 · 8초 주기 행동
- 바닥 한계: `FLOOR_FEET`(신발 바닥이 설 수 있는 가장 뒤쪽 바닥선, 화면 아래 %). 배경 cover 때문에 세로 화면(≈20%)과 가로 화면(≈16%)이 달라 `updateFloor()` 가 리사이즈마다 이미지 80% 지점으로 계산. `maxYFor` 가 신발 bbox 하단 기준으로 제한 → 소파 위로 못 올라감. 앞(카메라 쪽)과 좌우 이동은 기존대로.
- 8초 구간: `CHAOS_SECONDS=8`. 앵커 사건(레벨의 구도 깨기, 시각표 ×8/3) + 인물별 주기 행동(필러, 1.5~2.5초 간격, 서로 0.45초 이상 어긋남, 행동 후 hold 1.1~1.5초 뒤 원래 자세로 복귀). seed 가 같으면 같은 일정. 말풍선은 앵커와 sev≥2 필러만.
- 시간 종료: 자동으로 찰칵(토스트 '시간 끝! 자동으로 찰칵'), 마지막 순간의 포즈로 평가. 남은 시간은 상단 타이머(8→1), 마지막 3초는 큰 숫자.
- 점수: 동시 사고 보너스 250→120, 등급 기준 funny 60→70 / disaster 150→260 / 전설(L3) 230→460. 8초에서는 두 명 이상이 동시에 사고 포즈인 순간이 흔해 기존 값이면 대참사·전설이 과다.
- 등급 분포(셔터 시각 균등, 구도 완벽, seed 300): 평범 20~30% / 제법웃김 31~41% / 대참사 33~38% / 전설 L3 5%.
- 알려진 한계: L3 은 고양이가 구도를 영구히 깨지 못해(포즈는 복귀) 놓친 자동촬영이 최고점의 85% 이내인 판이 39%. 중간 동작 이미지 없음(정지 이미지 교체).
