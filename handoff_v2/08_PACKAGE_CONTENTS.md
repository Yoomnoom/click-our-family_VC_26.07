# 패키지 구성표

| 경로 | 용도 |
| --- | --- |
| `dist/index.html` | 현재 실행 가능한 게임 코드 |
| `dist/assets/` | 배경·가족·행동·동물 이미지 전체 |
| `handoff_v2/00_START_HERE.md` | V2 인계 시작점 |
| `handoff_v2/01_CLAUDE_MASTER_PROMPT.md` | 클로드에게 전달할 상세 지시 |
| `handoff_v2/02_PRODUCT_SPEC.md` | 문제·사용자·핵심 재미·범위 |
| `handoff_v2/03_GAME_RULES_SCORING.md` | 조건 판정·사고 타임·점수·등급 |
| `handoff_v2/04_UX_SCREEN_SPEC.md` | 화면별 UI와 문장 규칙 |
| `handoff_v2/05_TECHNICAL_PLAN.md` | 함수·데이터·저장·구현 순서 |
| `handoff_v2/06_QA_ACCEPTANCE.md` | 테스트와 완료 기준 |
| `handoff_v2/07_ASSET_AND_COPY_GUIDE.md` | 이미지·문구 가이드 |
| `handoff_v2/diagrams/` | 게임 루프·상태·점수 다이어그램 |
| `handoff_v2/mockups/v2_mobile_wireframes.svg` | 브리핑·배치·사고·결과 모바일 목업 |
| `docs/` | 이전 MVP PRD와 인계 기록 |
| `.openai/hosting.json` | 현재 정적 배포 설정 |

## 패키지 기준

- V2는 아직 구현물이 아니라 상세 제작 명세다.
- 현재 실행 파일은 기존 버전이며 V2와 비교·재사용하기 위해 포함했다.
- 클로드는 V2를 거실 3레벨부터 구현한 뒤 테스트 결과를 보고해야 한다.
