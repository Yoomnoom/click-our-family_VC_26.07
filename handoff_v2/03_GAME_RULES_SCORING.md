# 게임 규칙과 점수

## 라운드 상태

1. `briefing`: 조건 카드 확인
2. `staging`: 자유 배치, 시간 압박 없음 또는 12초의 느슨한 제한
3. `ready`: 필수 조건 2개 이상 충족
4. `chaos`: 3초 카운트다운, 돌발 행동 시작
5. `capture`: 셔터 순간의 상태 저장
6. `result`: 사진·점수·등급

## 조건 판정

픽셀 완전 일치가 아니라 허용 범위를 사용한다.

- 화면 안: 캐릭터 이미지 박스의 90% 이상이 stage 내부
- 얼굴 보임: 캐릭터끼리 얼굴 중심 거리가 stage 폭의 10% 이상
- 가까움: 두 캐릭터 중심 거리가 stage 폭의 22% 이하
- 뒤쪽: bottom 값이 상대보다 6% 이상 큼
- 크게: 렌더링 높이가 다른 인물 평균보다 12% 이상 큼
- 중앙: 얼굴 중심 x가 15~85%, y가 15~80%
- 삼각 구도: 세 얼굴의 삼각형 면적이 최소값 이상이며 일직선이 아님

## 촬영 가능 조건

- 세 조건 중 두 개를 만족하면 셔터 활성화
- 세 개 만족 시 셔터에 금색 링과 “완벽한 구도” 표시
- 두 개만 만족해도 진행 가능
- 한 개 이하는 셔터를 누를 수 있지만 구도 경고 후 촬영

## 사고 타임

- 조건 두 개 충족 시 `촬영 준비!` 버튼이 아니라 자동 0.6초 안내 후 시작
- 화면 상단에 3→2→1 표시
- 사고는 사전에 정한 레벨 테이블에 따라 발생
- 플레이어가 언제든 셔터 가능
- 0초가 되면 자동 촬영

## 위험과 보상

- 3초에서 촬영: 구도 유지 확률이 높고 순간 점수 낮음
- 2초에서 촬영: 행동 1개 포착 가능
- 1초에서 촬영: 행동 2개 또는 동물 난입 가능
- 0초 자동 촬영: 가장 큰 사고 가능, 구도 붕괴 위험

## 점수

### 구도 점수 0~100

- 조건 1개당 25점
- 화면 안 인물 1명당 5점
- 최대 100점

### 순간 점수 0~100

- 특수 자세 1명: 30점
- 특수 자세 2명: 65점
- 특수 자세 3명 이상: 100점
- 동물 난입만으로는 순간 점수에 20점 추가하되 최대 100점

### 사고 보너스

- 눈 감기: +80
- 점프: +100
- 과한 브이: +100
- 엄마의 급한 이동: +120
- 두 명 동시 딴짓: +250
- 고양이 중앙 난입: +300
- 세 사건 동시 포착: 추가 +350

### 총점

`총점 = 구도 점수 × 6 + 순간 점수 × 4 + 사고 보너스`

점수보다 등급을 먼저 보여준다.

## 사진 등급

| 등급 | 조건 |
| --- | --- |
| 평범 | 총점 0~499 |
| 제법 웃김 | 500~799 |
| 대참사 | 800~1099 |
| 전설의 가족사진 | 1100 이상 또는 3사건 동시 포착 |

## 결과 우선순위

1. 전설/대참사 등급 연출
2. 결과 사진
3. 한 줄 제목
4. 구도·순간·사고 점수
5. 다음 사진 버튼
6. 다시 찍기와 앨범은 보조 버튼
