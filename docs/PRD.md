# 찰칵! 우리 가족 — 공모전용 웹게임 PRD

## 한 줄 정의

말 안 듣는 가족을 제한 시간 안에 자유롭게 배치하고, 완벽하거나 웃기게 망한 순간을 사진과 앨범으로 남기는 짧은 반복형 가족 코미디 게임.

## 전달 감정

가족은 마음대로 통제되지 않지만 어긋난 순간까지 함께 남기면 추억이 된다. 정답 사진만 성공이 아니다.

## 핵심 목표

- 10초 안에 드래그와 촬영을 이해한다.
- 한 판만 플레이해도 돌발 행동과 실패의 재미를 본다.
- 각 라운드는 약 8~23초 안에 끝난다.
- 실패해도 같은 레벨을 강제로 반복하지 않는다.
- 게임에서 만든 구도가 결과 사진에 그대로 나온다.

## 핵심 루프

난이도 선택 → 규칙 확인 → 가족 배치 → 돌발 행동 대응 또는 포착 → 촬영 → 결과·스티커 → 다음 사진 → 9장 앨범 완성.

## 난이도

| 난이도 | 시간 | 사건 빈도 | 특징 |
| --- | --- | --- | --- |
| 편안하게 | +5초 | 낮음 | 조작과 배치 중심 |
| 보통 | 기본 | 중간 | 추천 난이도 |
| 대환장 | -3초 | 높음 | 첫 사건부터 두 명 딴짓과 동물 난입, 점수 1.25배 |

## 콘텐츠

- 가족: 엄마, 아빠, 누나, 동생
- 장면: 거실, 생일, 소풍
- 레벨: 장면별 3개, 총 9개
- 가족별 돌발 자세 2종
- 고양이·강아지 난입
- 실패 효과: 손떨림, 손가락 가림, 플래시 과노출
- 결과 스티커와 상황별 문구

## 점수 원칙

발 마커 배치, 남은 시간, 규칙 달성, 전원 정상 포즈, 딴짓 포착, 동시 딴짓, 동물 난입, 난이도 배율을 반영한다. 완벽한 사진과 웃긴 실패 사진 모두 높은 점수가 가능해야 한다.

## 저장

- 서버 없이 브라우저 `localStorage` 사용
- 선택 난이도, 현재 레벨, 최고 점수 저장
- 최근 촬영 기록 12장 저장
- 이미지 파일 대신 배경·좌표·상태·점수 데이터를 저장해 재구성

## 제외 범위

로그인, 서버 저장, 온라인 랭킹, 결제, 장편 스토리, 실시간 멀티플레이, 실사 카메라 촬영, 복잡한 캐릭터 커스터마이징.

## 공모전 시연 포인트

1. 가족을 장식이 아니라 제멋대로 움직이는 게임 규칙으로 사용한다.
2. 실패가 게임오버가 아니라 웃긴 결과물과 앨범이 된다.
3. 첫 판부터 돌발 상황이 발생한다.
4. 가족·배경·행동을 추가하기 쉬운 구조다.

## 완료 기준

- 모바일에서 캐릭터가 드래그 중 사라지지 않음
- 배치와 촬영 결과의 위치·크기·앞뒤 관계 일치
- 세 난이도 모두 완주 가능
- 9레벨 진행 및 앨범 완성 가능
- 시간 종료와 수동 촬영 모두 정상 작동
- 새로고침 후 진행 정보와 앨범 유지
- 이미지 누락과 JavaScript 오류 없음
