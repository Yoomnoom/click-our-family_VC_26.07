## 결정 기록 (사용자에게 물을 수 없어 내린 판단)
1. **역할 배정 수정 없음**: 시트 4장·24장을 직접 보고 §2 표가 그림과 일치함을 확인(얼굴 가림 3개: 엄마 p3 · 아빠 p1 · 누나 p1).
2. **인물 크기 비율**: 24장이 같은 캔버스 + 같은 스케일이면 눈에 보이는 높이가 자연히 아빠 502 : 엄마 486 : 누나 447 : 동생 395(1 : .97 : .89 : .79)이므로 컨테이너 높이는 모두 같게(세로 화면 35%, 가로 44%) 두고 인물별 보정을 두지 않음(단위 테스트로 비율 확인). V2.1의 인물별 CSS 크기는 이미지 여백이 없던 시절 값이라 폐기.
3. **점프 이중 이동 처리**: 누나 p3·동생 p4는 추가 상승 없음. V2.1의 0.3초 튀기(bounce)와 동생 +12% 점프 이동을 폐기. 동생 p4의 구도 붕괴는 사고 시 이동(`dys`)으로만 처리.
4. **연쇄 반응 대상 선택 규칙**: 반응 포즈가 있는 인물 중 고양이 위치(stage 중앙, 가로 50%·세로 중심 22%)와 눈에 보이는 영역 중심의 거리(폭 단위)가 가까운 순, 동률이면 인물 ID 사전순, 최대 2명. L3 시작 배치는 누나가 항상 아빠보다 고양이에 가깝도록 비대칭(아빠 18 / 누나 66)으로 두어 지터로 결과가 달라지지 않게 함(시뮬레이션·브라우저 결과 일치).
5. **점수는 '지금 화면의 포즈 상태' 기준으로 변경**: 사고별 포착 시각 판정을 폐기. 에스컬레이션·연쇄 반응으로 같은 인물의 포즈가 바뀌는 구조에서는 "마지막 포즈의 점수"가 가장 자연스럽고, 사진에 보이는 것과 점수가 항상 일치함.
6. **"두 명 동시 딴짓 +250"**: 사고 포즈가 2명 이상이면 레벨 무관 적용(L1·L2 두 사고 동시 포착 포함).
7. **등급 임계값**: 사고 점수 기준(웃김 60 / 대참사 150). L3 전설은 사고 점수 230으로 낮춤(두 번째 사고로 구도가 절반 깨진 상태의 사고 점수 약 237). V2.2의 L3 타임라인에서는 500이면 전설이 도달 불가였음. L1·L2 전설은 V2.1 결정 유지(없음).
8. **연출 보너스 수치**: V2.2 §5-4 공식 그대로(조정 없음). 시뮬레이션은 연출 0명 기준 표를 쓰고, 연출 3명이면 구도 +80(4×20)이 더 붙음.
9. **L3 정답 구도의 특수 자세 담당은 누나**: 사고 인물(아빠·엄마)이 특수 자세 담당이면 사고가 연출 포즈를 덮어써 조건이 즉시 깨져 시뮬레이션이 왜곡됨.
10. **버그 수정 두 건(작업 중 발견)**: ① `planMoves`의 동률 비교가 `b.cost`(undefined)를 보아 "최소 이동 우선"이 작동하지 않던 V2.1부터의 버그 → `b.c.cost`. ② 새 `.pop` 클래스가 조건 카드의 `.cond.pop`과 충돌해 사고 타임에 카드 두 장이 겹쳐 보이던 문제(스크린샷으로 발견, e2e 통과로는 못 잡음) → `.pose-pop`.
11. **포즈 교체 시 화면 안 보정**(`fitInStage`, `withPose` 클램프): 가로로 넓은 포즈로 바뀌면 기존 x에서 화면 밖으로 밀리는 문제(결과 사진에서 아빠 팔이 잘림)를 스크린샷으로 발견.
12. **전체 규칙 중 V2.1 §4~§6의 그 외 항목은 유지**(저장 키, 금지 사항, 모바일 방어, 질문 금지 원칙).
