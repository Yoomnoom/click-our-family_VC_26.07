# 앞으로 만들어야 할 정보와 기능

## 공모전 전 필수 — P0

### 1. 실제 모바일 드래그 회귀 테스트

- 안드로이드 크롬에서 빠른 위·아래·대각선 쓸기 각 20회
- 인물이 사라지거나 화면 밖으로 빠지지 않아야 함
- 드래그 도중 손가락이 화면 밖으로 나가도 조작 상태가 풀려야 함
- 촬영 전 배치와 촬영 후 결과가 같아야 함

### 2. 첫 판 전달력

- 첫 화면에서 난이도 차이를 즉시 이해
- 보통은 추천 표시 유지
- 대환장은 첫 사건에서 두 명 동시 딴짓과 동물 난입
- 첫 촬영 전 미션 규칙이 팝업으로 읽혀야 함
- 미션 중 핵심 규칙을 짧은 토스트로 다시 확인 가능

### 3. 텍스트 QA

- “딴짓을 기다려요”처럼 마지막 한 글자만 줄바꿈되지 않게 함
- 작은 화면에서 말줄임으로 규칙 핵심이 사라지지 않게 함
- 결과 사진 캡션은 두 줄 이내
- 버튼 문구는 한 줄 유지

### 4. 인물 가시성

- 기본·돌발 자세 모두 전신이 잘리지 않음
- 얼굴 크기 기준으로 가족 간 비율 정리
- 키 큰 아빠는 같은 구도에서 뒷줄이 자연스러움
- 완전 겹침은 경고하되 사용자의 자유 배치를 강제로 바꾸지 않음

## 완성도 강화 — P1

### 5. 효과음과 진동

- 셔터, 마커 안착, 딴짓, 동물 난입 효과음
- 모바일 짧은 진동
- 소리·진동 ON/OFF 버튼
- 자동 재생 제한을 고려해 첫 사용자 입력 이후만 재생

### 6. 앨범 개선

- 사진 한 장씩 PNG 저장
- 스티커·점수·장면·레벨 표시 정리
- 9장 완료 화면에 “오늘의 가족상” 1개 제공
- 전체 삭제는 실수 방지 확인창 포함

### 7. 결과 다양성

- 가족별 결과 문구 추가
- 두 명 조합별 합동 딴짓 문구
- 동물과 가족 행동이 함께 찍힌 복합 결과
- 같은 문구가 연속으로 반복되지 않게 최근 결과 기억

### 8. 조작 피드백

- 잡은 인물의 윤곽 또는 살짝 커지는 반응
- 마커 근처에서 흡착 예상 표시
- 놓을 수 없는 가장자리에서 부드러운 저항감
- 겹친 가족을 다시 선택할 수 있는 선택 우선순위

## 공모전 이후 — P2

- 가족 구성 선택: 2~6명
- 할머니·할아버지·아기·반려동물 캐릭터
- 명절·졸업식·여행 배경
- 주간 사진 챌린지
- 실제 사진 업로드나 서버 기능은 별도 제품 검증 후 결정

## 만들지 않을 것

- 공모전 전에 로그인, 서버, 온라인 랭킹, 결제
- 장문의 스토리 모드
- 정밀 물리 엔진
- 캐릭터 꾸미기 상점
- 실사 카메라 권한 기능

## 최종 제출 전 체크

- 첫 플레이 60초 안에 최소 두 장 촬영 가능
- 심사위원이 설명 없이 셔터까지 도달
- 실패 결과를 보고 웃을 만한 시각적 사건이 보임
- 새로고침·뒤로가기 후 치명적 오류 없음
- 모든 이미지 출처와 생성 방식 정리
- 발표용 30초 시연 순서 준비
