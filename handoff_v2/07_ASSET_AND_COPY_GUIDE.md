# 자산과 문구 가이드

## 재사용 자산

- `living-room.png`
- `mom-v2.png`, `dad-v2.png`, `sis-v2.png`, `bro-v2.png`
- 각 인물의 `action.png`, `action2.png`
- `photo-cat.png`, `photo-dog.png`

## 이미지 원칙

- 기존 따뜻한 2D 그림책 톤 유지
- 인물 전신 잘림 금지
- 투명 PNG 가장자리 잔여물 금지
- 기본 자세와 행동 자세의 얼굴 크기 차이 최소화
- 새 이미지는 당장 만들지 말고 기존 자산으로 재미 검증

## UI 문구 예시

### 조건

- 얼굴 3개 보이기
- 아빠는 뒤로!
- 한 명은 크게
- 둘은 꼭 붙기
- 한 명은 딴짓
- 모두 화면 안에

### 사고 타임

- 사진 망가지기 3초 전!
- 아빠 눈 감는다!
- 동생 날아간다!
- 고양이가 온다!
- 지금 찍으면 전설!

### 결과

- 아빠는 꿈속, 동생은 공중
- 고양이가 가족 대표가 됨
- 완벽했는데 1초가 문제
- 아무도 카메라를 안 봄
- 이 집 단체사진은 무리였다

## 금지 문구

- “실패했습니다”
- “다시 도전하세요”를 주 CTA로 사용
- 긴 규칙 설명
- 누가 잘못했는지 플레이어를 탓하는 문장
