# QA와 완료 기준

## 기능 완료

- 거실 3레벨이 처음부터 끝까지 이어짐
- 각 레벨 조건 3개가 실시간으로 판정됨
- 조건 2개 이상에서 사고 타임 진입
- 사고 타임 중 언제든 촬영 가능
- 시간 종료 시 자동 촬영
- 결과에 등급과 세 점수 항목 표시
- 실패해도 다음 레벨 진행
- 결과가 앨범에 저장

## 핵심 재미 검증

- 첫 레벨 시작 10초 안에 목표 이해
- 한 판에서 최소 1개 사고 발생
- 대환장 첫 판에서 2개 이상 사건 포착 가능
- 결과 제목만 읽어도 무엇이 망했는지 이해
- 플레이어가 안전 촬영과 기다리기 중 선택할 이유가 있음

## 모바일

- 360×640
- 390×844
- 412×915
- 768×1024

각 크기에서 확인:

- 글자 한 글자 낙하 없음
- 버튼 잘림 없음
- 캐릭터 전신 보임
- 위·아래·대각선 빠른 드래그 각 20회
- 드래그 중 캐릭터 사라짐 없음
- 결과 사진과 배치 일치

## 회귀

- 앨범 열기/닫기
- 새로고침 후 기록 유지
- 이미지 404 없음
- 콘솔 오류 없음
- 기본/행동1/행동2 이미지 모두 표시
- 고양이 난입 좌표가 결과에 보존

## 사용자 테스트 질문

설명하지 않고 플레이시킨 뒤 묻는다.

1. 무엇을 하는 게임이라고 이해했나요?
2. 언제 셔터를 누를지 고민했나요?
3. 결과 사진에서 무엇이 웃겼나요?
4. 한 판 더 하고 싶나요?

네 문항 중 세 문항이 긍정적이면 9레벨 확장. 두 개 이하면 콘텐츠 추가 금지, 핵심 루프 재검토.
